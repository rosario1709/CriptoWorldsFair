# Business hypothesis

ProofCommerce provides verified settlement infrastructure for autonomous commerce. Potential customers include AI agent companies, agent marketplaces, API/data/compute providers and AI infrastructure platforms.

A conceptual fee of **0.25% per verified settlement** is a pricing hypothesis, not deployed contract behavior. The MVP charges **zero protocol fees**; network transaction fees still apply. No revenue, TVL, user count or traction is claimed from fixture identities or tests.

Possible product lines:

- **ProofCommerce Protocol:** agreement and verified settlement primitives.
- **ProofCommerce SDK:** developer integration and agent workflows.
- **ProofCommerce Cloud:** managed verification, policies, analytics, observability and future compliance tooling.

Early validation should measure integration time, failure detection, refund latency, signer operating costs and willingness to pay. Weather is a reproducible infrastructure example, not the target business. Subjective deliverables require stronger verification and dispute models before automation can be trusted.
